# 日出日落資料轉換工具

### 用途：

把氣象署各縣市[日出日沒時刻表](https://www.cwa.gov.tw/V8/C/D/astronomy_data.html)PDF，轉成data/suntime-YYYY.json

```text
Taiwan Weather Dashboard/
├─── SUN/
|    └─── 20YY #新增年份資料夾
|         └─── XXX.pdf
|                #每個縣市該年份的日出日沒時刻表，共22個
├─── data/
|    └─── suntime-20YY.json #最終生成檔
└─── pdf_to_json.py #執行檔
```

### 事前準備：

- 套件：pip install pdfplumber == x.x.x (版本號用pip show pdfplumbert查)
- 在目標資料夾內新增該年份資料夾 (SUN/20YY)
- 下載該年份各縣市的PDF檔，並改名為對應縣市名 (✔️臺 ❌台)，存在年份資料夾內

### 執行要點：

- 進到執行檔編輯「YEAR」到對應年份再執行
- 程式會依序檢查pdf檔內以下項目，任一項不通過，就會列出是哪些縣市有問題，並不輸出 JSON:
  - 檔案數量: 是否22個縣市都在
  - 年份: 每頁標題的西元年份是否與YEAR一致
  - 縣市名: 每頁標題的縣市是否與檔名一致
  - 數據數量: 每個月的日出、日沒筆數是否正確，全年是否為365筆(閏年366筆)

### 出現 TODO_FIX：

- PDF偶爾會有異樣數據，如誤寫為0.724這種非時間的
  - 若還有其他問題存在：會在「天數(資料格異常)」顯示哪裡有異狀，得先把其他問題解決
  - 若只剩這個問題存在：會照常輸出 JSON，且將該項異樣數據填為「TODO＿FIX＿編號」，同時也會列出是屬於哪個縣市、哪天的日出或日沒
- 處理：到 JSON 內搜尋「TODO_FIX」即可逐一找到並手動修正
